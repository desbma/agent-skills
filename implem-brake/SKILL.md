# Implementation brake

`on`, the default without argument: do not create, modify or delete any project file. Reading, searching, building and testing stay open. We discuss; when a change is needed, say which one and why. Only my `off` lifts this — not my approval of your proposal.

`off`: you may change code again. Implementation is likely what I want next, but raise any open point before starting.
